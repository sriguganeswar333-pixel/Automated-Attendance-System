ℹ️ Attendance System Information

The attendance system automatically allows attendance only between 08:30 AM and 04:00 PM India Standard Time.

Each student can be marked present only once per day. Attendance is automatically available again on the next day.

Face recognition identifies the registered student and stores the attendance date, time and student ID in the database.
